# AI-Powered Workplace Productivity Assistant

## Project Overview

The AI-Powered Workplace Productivity Assistant is a web-based application designed to help professionals automate repetitive workplace tasks using Artificial Intelligence. The solution improves efficiency, saves time, and enhances productivity by providing AI-powered tools for email generation, meeting summarization, task planning, research assistance, and workplace support.

This project was developed as part of the AI Skill Accelerator Programme to demonstrate practical AI implementation, prompt engineering, responsible AI usage, and workplace productivity enhancement.

---

## Features

### 1. Smart Email Generator

* Generates professional emails based on user input.
* Supports multiple tones:

  * Formal
  * Informal
  * Persuasive
* Adapts content for different audiences:

  * Clients
  * Managers
  * Team Members

### 2. Meeting Notes Summarizer

* Converts lengthy meeting notes into concise summaries.
* Extracts:

  * Key discussion points
  * Decisions made
  * Action items
  * Deadlines
  * Assigned responsibilities

### 3. AI Task Planner

* Creates structured daily and weekly schedules.
* Prioritizes tasks based on urgency and importance.
* Provides productivity and time-management recommendations.

### 4. AI Research Assistant

* Summarizes articles, reports, and research topics.
* Highlights key insights and recommendations.
* Simplifies complex information for quick understanding.

### 5. Workplace Assistant Chatbot

* Provides conversational AI support.
* Handles multiple workplace-related queries.
* Offers quick access to all productivity tools.

### Responsible AI Features

* AI-generated content disclaimer.
* Regenerate output functionality.
* Input validation checks.
* Transparency regarding AI limitations and potential inaccuracies.

## Setup Instructions

### Prerequisites

* Node.js (v18 or later)
* npm or yarn package manager

### Installation

1. Clone the repository:

```bash
git clone https://github.com/yourusername/ai-productivity-assistant.git
```

2. Navigate to the project folder:

```bash
cd ai-productivity-assistant
```

3. Install dependencies:

```bash
npm install
```

4. Create an environment file:

```bash
.env
```

Add your API key:

```env
OPENAI_API_KEY=your_api_key_here
```

5. Start the development server:

```bash
npm run dev
```

6. Open your browser and navigate to:

```text
http://localhost:3000
```
